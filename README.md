# nanquim-frases

Arquivos que o app Nanquim busca sozinho ao abrir.

- `semana.tsv`: as 20 frases de inglês da semana (6 colunas: English, Português, Como falar, Contexto, Variações, Tema).
- `agronomia.tsv`: cartões técnicos de agronomia em português (3 colunas: pergunta, resposta, tema). Vão para o baralho "Agronomia técnica".
- `arquivo/`: cópias antigas.

O app guarda o que já recebeu e não recoloca um cartão que você apagou.
